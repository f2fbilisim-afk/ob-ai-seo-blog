# OB AI SEO Blog (WordPress)

Toplu anahtar kelime listesinden OpenAI ile SEO makale üretir; Rank Math alanları, kapak ve inline görseller; anında veya planlı yayın.

**Merkezi API:** `https://api.f2fbilisim.com` — müşteri sitesinde OpenAI anahtarı gerekmez; **OBAI-…** lisans (`product: seo-blog`) yeterlidir.

## Kurulum

1. Eklentiyi `wp-content/plugins/ob-ai-seo-blog` altına kopyalayın veya Releases zip’ini yükleyin.
2. WordPress **Eklentiler** → **OB AI SEO Blog** etkinleştirin.
3. **Ayarlar:** API adresi `https://api.f2fbilisim.com`, lisans anahtarınız.
4. Anahtar kelimeleri satır satır girin ve kuyruğu çalıştırın.

## Gereksinimler

- WordPress 6.0+, PHP 7.4+
- Rank Math (önerilir)
- Geçerli **SEO Blog** lisansı (F2F chatbot anahtarları bu eklenti için geçerli değildir)
